# 画质升级与 DV/HDR 阶梯

采集 agent 在**召回之后**读候选标题选片。搜索始终用裸标题（片名/译名）；画质词（含 4K、DV、DoVi、HDR10+、HDR、杜比视界、Remux、WEB-DL、Atmos、超高清、无压）会被系统 strip，不要写进搜索关键词。

## 完整比较阶梯（默认开启，作召回后排序）

从高到低、按轴依次比较。后一轴只在前一轴打平时才起作用：

1. **分辨率**（默认优先）
   - 高档 ≈4K / 2160p > 1080p > 720p > SD
   - 中档以 1080p 为目标，4K / Remux 视为超标
   - 不限也会按阶梯弱优先，但不强制某一档
   - 中文别名：超高清 ≈4K，全高清 / 超清 / 2K ≈1080p
2. **HDR**：Dolby Vision / DoVi / DV / 杜比视界 > HDR10+ > HDR10 / HDR > SDR / 未标注
3. **片源 / 压制**（可关）：Remux / 无压 > BluRay / BDRip / 蓝光 > WEB-DL / 官源 / **未标注** > WEBRip > HDTV > CAM / 枪版 / 尝鲜版
   - 标题没写来源时按 WEB-DL 看待，不因缺标签就降级
4. **音轨**（只作同分决胜）：Atmos / 杜比全景声 > TrueHD > DTS-HD > 未标注
   - 缺音轨标签不会单独触发替换

与分辨率的组合（默认分辨率优先）：

- 4K DV 优于 4K SDR
- **不要**用 1080p DV 压过 4K SDR，除非打开「HDR 优先于分辨率」
- **不要**用 1080p Remux 压过 4K WEB-DL（分辨率仍先于片源）

中文字幕规则不变：覆盖优先；中档位仍可为一档中字破上限。

设置位置：设置 → 获取偏好 → 偏好画质（可视化阶梯会随开关即时更新）。Agent API：`preferHdrOverResolution`（默认 `false`）、`considerSourceClass`（默认 `true`）、只读字段 `qualityLadderSummary`。

## 当前画质怎么判断

详情页和定时升级都读**盘里真实文件名**（以及能解析的分享标题），再和用户偏好对比。没有分辨率 / HDR / 片源标签时会如实写「未能从已入库文件名判断画质」，**不会假装可以升到 4K**。

能解析时详情会写成例如「现在 1080p WEB-DL → 可升 4K 杜比视界」。已经位于偏好阶梯顶部（如高档下的 4K 杜比视界 Remux）则显示「已达偏好阶梯顶部」。

点「升级画质」会先弹出现在 / 将寻找对照，确认后才排队。失败不会删除旧文件。

## 画质升级 / 替换（默认关闭自动路径）

已入库标题默认不会被巡检重写。只有下面几条路径会替换**严格更高**的候选（同等或更低不换；原盘/ISO 不会替换可播放视频）：

1. **详情页「升级画质」** — 始终可用。入队前预览现在→目标。
2. **重新获取时允许画质升级**（`upgradeOnReacquire`，默认关）— 打开后，对已入库标题再点获取 / Agent `acquire` 会排队升级而不是返回 already_tracked。
3. **定时画质升级**（`patrolQualityUpgrade`，默认关）— 与**定时追更补集**是两项独立任务，**共用同一组每日巡检时间**，不另开 cron。打开后，巡检会：
   - 继续补缺（缺集 / 未入库）
   - 并对已入库电影、已完结季、以及没有缺集的追更中标题寻找严格更高版本
   - 若盘内文件名已表明达到偏好阶梯顶部，本轮跳过，避免空跑
   - 文件名无法判断时仍会跑（agent 会 `inspectTargetDir`）

开关位置：设置 → 巡检与通知 → 每日定时巡检（与追更补集并排）；偏好画质页里是同一项。

Agent API 字段：`upgradeOnReacquire`、`patrolQualityUpgrade`。`POST /api/agent/acquire` 可带 `"qualityUpgrade": true` 做一次显式升级。

成功转存并回读验证后，agent 应删除被替换的低画质文件，使库/覆盖状态与网盘文件一致。升级失败不会清掉已入库集。

活动页排队/进行中的升级任务会标「升级画质」；替换成功的通知 kind 为 `quality_upgrade`。媒体库海报上的标记只表示「打开详情可以对比并升级」，不是系统已经确认盘里是低画质。

## 如何打开

1. 设置 → 获取偏好 → 偏好画质：选分辨率档位，看阶梯预览；需要时展开「更多排序规则」。
2. 若希望对已入库标题再点获取就升级：勾选「重新获取时允许画质升级」，保存。
3. 若希望定时巡检也升级：设置 → 巡检与通知 → 每日定时巡检，打开「定时画质升级」（与追更补集共用时间点）。
4. 或对单部已入库作品点详情页「升级画质」，确认现在→目标后再排队。

## 本版不做（后续）

- 媒体库一次勾选多部批量升级
- 单部 / 单季覆盖全局画质偏好
- 完全可拖拽的自定义阶梯权重编辑器
