# 画质升级与 DV/HDR 阶梯

采集 agent 在**召回之后**读候选标题选片。搜索始终用裸标题（片名/译名）；画质词（含 4K、DV、DoVi、HDR10+、HDR、杜比视界）会被系统 strip，不要写进搜索关键词。

## HDR 阶梯（默认开启，作召回后排序）

同一分辨率内，从高到低：

1. Dolby Vision / DoVi / DV / 杜比视界
2. HDR10+
3. HDR10 / HDR
4. SDR / 未标注

与分辨率的组合（默认分辨率优先）：

- 4K DV 优于 4K SDR
- **不要**用 1080p DV 压过 4K SDR，除非打开「HDR 优先于分辨率」

设置位置：设置 → 偏好 → 偏好画质。Agent API：`preferHdrOverResolution`（`GET/PUT /api/agent/config`，默认 `false`）。

分辨率档位仍是原来的「高 ≈4K / 中 ≈1080p / 不限」。不限也会按 HDR 阶梯在候选里排序，只是不强制 4K 或 1080p 档位。中文字幕规则不变：覆盖优先；中档位仍可为一档中字破上限。

## 画质升级 / 替换（默认关闭）

已入库标题默认不会被巡检重写。只有下面几条路径会替换**严格更高**的候选（同等或更低不换；原盘/ISO 不会替换可播放视频）：

1. **详情页「升级画质」** — 显式排队升级任务（剧：在该季展开区；电影：已入库时显示）。
2. **重新获取时允许画质升级**（`upgradeOnReacquire`，默认关）— 打开后，对已入库标题再点获取 / Agent `acquire` 会排队升级而不是返回 already_tracked。
3. **巡检时也升级画质**（`patrolQualityUpgrade`，默认关）— 打开后，定时巡检才会扫已完结季和已入库电影。默认巡检仍然只补缺。

Agent API 字段：`upgradeOnReacquire`、`patrolQualityUpgrade`。`POST /api/agent/acquire` 可带 `"qualityUpgrade": true` 做一次显式升级。

成功转存并回读验证后，agent 应删除被替换的低画质文件，使库/覆盖状态与网盘文件一致。升级失败不会清掉已入库集。

## 如何打开

1. 设置 → 偏好画质：勾选「重新获取时允许画质升级」，可选「HDR 优先于分辨率」，保存。
2. 若希望定时巡检也升级：设置 → 每日定时巡检 → 勾选「巡检时也升级画质」，保存。
3. 或对单部已入库作品点详情页「升级画质」。
