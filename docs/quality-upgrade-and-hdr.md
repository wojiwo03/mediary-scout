# 画质升级与 DV/HDR 阶梯

采集 agent 在**召回之后**读候选标题选片。搜索始终用裸标题（片名/译名）；画质词（含 4K、DV、DoVi、HDR10+、HDR、杜比视界、Remux、WEB-DL、Atmos）会被系统 strip，不要写进搜索关键词。

## 完整比较阶梯（默认开启，作召回后排序）

从高到低、按轴依次比较。后一轴只在前一轴打平时才起作用：

1. **分辨率**（默认优先）
   - 高档 ≈4K / 2160p > 1080p > 720p > SD
   - 中档以 1080p 为目标，4K / Remux 视为超标
   - 不限也会按阶梯弱优先，但不强制某一档
2. **HDR**：Dolby Vision / DoVi / DV / 杜比视界 > HDR10+ > HDR10 / HDR > SDR / 未标注
3. **片源 / 压制**（可关）：Remux > BluRay / BDRip / 蓝光 > WEB-DL / **未标注** > WEBRip > HDTV > CAM / 枪版
   - 标题没写来源时按 WEB-DL 看待，不因缺标签就降级
4. **音轨**（只作同分决胜）：Atmos / 杜比全景声 > TrueHD > DTS-HD > 未标注
   - 缺音轨标签不会单独触发替换

与分辨率的组合（默认分辨率优先）：

- 4K DV 优于 4K SDR
- **不要**用 1080p DV 压过 4K SDR，除非打开「HDR 优先于分辨率」
- **不要**用 1080p Remux 压过 4K WEB-DL（分辨率仍先于片源）

中文字幕规则不变：覆盖优先；中档位仍可为一档中字破上限。

设置位置：设置 → 获取偏好 → 偏好画质（可视化阶梯会随开关即时更新）。Agent API：`preferHdrOverResolution`（默认 `false`）、`considerSourceClass`（默认 `true`）、只读字段 `qualityLadderSummary`。

## 画质升级 / 替换（默认关闭）

已入库标题默认不会被巡检重写。只有下面几条路径会替换**严格更高**的候选（同等或更低不换；原盘/ISO 不会替换可播放视频）：

1. **详情页「升级画质」** — 始终可用。已入库电影、以及已有正片的季展开区会显示当前目标偏好，并排队升级任务。
2. **重新获取时允许画质升级**（`upgradeOnReacquire`，默认关）— 打开后，对已入库标题再点获取 / Agent `acquire` 会排队升级而不是返回 already_tracked。
3. **巡检时也升级画质**（`patrolQualityUpgrade`，默认关）— 打开后，定时巡检才会扫已完结季和已入库电影。默认巡检仍然只补缺。开关与「偏好画质」里是同一项。

Agent API 字段：`upgradeOnReacquire`、`patrolQualityUpgrade`。`POST /api/agent/acquire` 可带 `"qualityUpgrade": true` 做一次显式升级。

成功转存并回读验证后，agent 应删除被替换的低画质文件，使库/覆盖状态与网盘文件一致。升级失败不会清掉已入库集。

媒体库里已全部入库的海报会带一个画质标记，点进详情才能真正升级——这表示「可以发起升级」，不是系统已经确认盘里是低画质。

## 如何打开

1. 设置 → 获取偏好 → 偏好画质：选分辨率档位，看阶梯预览；需要时展开「更多排序规则」。
2. 若希望对已入库标题再点获取就升级：勾选「重新获取时允许画质升级」，保存。
3. 若希望定时巡检也升级：在同一页勾选「巡检时也升级画质」，或到「巡检与通知」查看当前状态。
4. 或对单部已入库作品点详情页「升级画质」。
